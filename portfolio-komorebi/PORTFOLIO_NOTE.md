# ポートフォリオ制作メモ：喫茶 木もれ日（架空店舗）

営業・提案用に、このサンプルの狙いを短くまとめたメモです。ポートフォリオサイトに載せる紹介文のベースにも使えます。

## コンセプト
個人店・小規模店舗のLP/HP制作を想定した架空案件。「近所の人が気軽に立ち寄れる、あたたかみのあるコーヒースタンド」というブランドイメージを、色・書体・イラストで一貫して表現しました。

## デザイン上の工夫
- ブランドカラーはコーヒーブラウン(#8a5a3b)で統一し、見出しには温かみのある明朝体（Shippori Mincho）を使用して個人店らしい親しみやすさを演出
- 写真素材を使わず、SVGの線画イラスト（コーヒーカップ・湯気アニメーション）で世界観を表現。納品前に実店舗の写真へ差し替えるだけで完成度を保てる設計
- 業種特化のセクション構成：一般的な「料金プラン」ではなく、実際の喫茶店の運用に合わせて「メニュー」「アクセス（地図・営業時間）」セクションを独自に追加

## 技術構成
プレーンHTML/CSS + Tailwind CSS（CDN版、ビルド不要）。フォームはFormspree等の外部サービスに接続する想定でマークアップ済み。全ページレスポンシブ対応、SEO用のtitle/description/OGP/構造化データ（JSON-LD）も設定済み。

## クライアントへの提案時に使えるトーク例
「個人店・小規模店舗様のLP制作を得意としています。こちらは架空のカフェを題材にしたサンプルですが、実際の店舗様の場合は、写真撮影のご協力とヒアリングをいただければ、1〜2週間程度で同水準のサイトを制作できます。」
